## Decisions

- **The walk folds through `Result.bind`** instead of `List.map` then `ItemEvaluation.sequenced`.
  - The slice says "the first error stops the walk".
  - `sequenced` collects results that are already evaluated, so every later run would still be bound and every later
    row solved.
  - Each fold step binds the previous result, so nothing after the first error is evaluated. The returned error is
    the same first error `sequenced` would give. A comment at the fold says why.
- **The order of the walk:**
  1. the run's assignment (step 373);
  2. its dark level: `data.darkOf` of the session in `layout.sessions` listing the run, else `None` (step 378);
  3. `boundWith` (step 375);
  4. `residualWeightOf name bound.detectorItem` (step 365);
  5. for each row, `predictedReadingOf` then `residualAgainst` (steps 375, 376).

  The measured reading of a settings row is the reading it carries. For an observation row it is
  `RecordedMueller observation.measured`.
- **The weight multiplies every entry of a row**, its throughput included, as the slice says ("every entry
  multiplied by the weight").
- **The layout** is every row's `elements` in run then row order, then every row's `throughputOpt` in the same order.
  This is `MuellerFitting.throughputResidualFor`'s order. Nothing else is added: no cache, scaling or penalty.
- **The ellipsometer run needs a bound detector slot.** `ExperimentDataLoad.detectorKindOf` reads the detector
  slot's library entry, not the item's model. A `LibraryModelChoice` item leaves the slot's `valueId` unset, which
  reads as Intensity, and the pre-fit would then refuse the Ψ/Δ series. The test-local `ellipsometerBench` therefore
  binds its detector slot to `PresetIds.detectorEllipsometer`, the Built-in Ellipsometer detector. Its analyzer is
  turned to 30°, so the arriving state is not a degenerate horizontal one.
- **The polarimeter fact's tolerance** is 1e-12 relative: `|e − a| ≤ 1e-12·|e|`. The parts agree bit for bit:
  - step 375 showed the plate's Mueller matrix equals `createBerremanForward ... muellerOf`;
  - `ofScaled` at the zero vector is the centre exactly;
  - a unit weight multiplies by 1.0.
- **The polarimeter fact's observations** are generated by `MuellerFitting.observeWith` from step 375's
  `observedParameters`, a crystal without gyration. The residual is evaluated at the crystal's own values
  (`uniaxialParameters`), so every entry is a real difference. The fact also asserts that some harness entry exceeds
  1e-6.
- **The mixed study's vector** is n_o alone, at 1.55. Freeing one component exercises the layout and the assignment
  without changing the fact's subject.
