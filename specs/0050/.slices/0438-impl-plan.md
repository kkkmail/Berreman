# Step 0438 — implementation plan

Commit the absorbing-biaxial-noisy reference kit as AT-2's build writes it, and prove it with a file-by-file fact
(spec 0050 S12.2; 001 §Q AT-2, §S12, §1).

## Approach

1. **`assertSameKitFiles`** (`KitAcceptanceTests.fs`): move step 428's inline comparison into the private
   `assertSameKitFiles (built : KitFolder) (other : KitFolder) : unit`.
   - It takes both folders' relative paths with `.oc/` left out (`kitContentFiles`) and walks their union in order.
   - It fails at the first difference, naming the built folder's absolute path, the relative path and why: missing
     from the other folder, extra in it, or different bytes.
   - Step 428's equality fact calls it over the built and committed folders.
   - Step 430's Send fact calls it over the built and received folders. Its own file-set and byte comparison goes;
     its counts and residual checks stay.
2. **The new fact** `the built absorbing-biaxial-noisy kit equals the committed kit file by file`:
   - It runs over `absorbingBuild`.
   - It finds the committed folder with `CommittedKit.AbsorbingBiaxialNoisyKit.tryFindFolder`. If there is none, the
     fact fails and names the built folder.
   - It then calls `assertSameKitFiles built.folder committed`. It writes nothing.
3. **The committed kit**, built once, never by hand:
   - Build the solution, then run the new fact filtered to itself. It fails because `data/absorbing-biaxial-noisy/`
     is missing (red).
   - Copy every file of the built `KitAcceptanceTests/AT-2/absorbing-biaxial-noisy/` except `.oc/` into
     `data/absorbing-biaxial-noisy/`, byte for byte.
   - Check that the files are LF only and that no file is git-ignored.
   - Run the gate's class selection (`KitAcceptanceTests`). This is the second run, and the new fact passes.
4. **`AGENTS.md`**: the reference-kit gotcha names `data/absorbing-biaxial-noisy/` as AT-2's output, its five
   observation files included, and names the new fact. It is rewrapped to stay within four lines. Nothing else in the
   file changes.

## Risks

- **Runtime:** AT-2's build includes a fit of about 800–950 s, and the build runs twice: the red run, then the class
  run. R0005's 1800 s fit bound is preserved, not changed.
- **Snapshot count:** the slice text lists four `library/` snapshots, but the build snapshots eight. Step 0433 found
  that the detector preset, three item models and the crystal category ride along. The step's effects authorize all
  of `library/`, and the acceptance asks for what the build writes, so the build's set is committed.
- **Line endings:** a CR byte in any generated file would be normalized by `.gitattributes`, so the committed bytes
  would stop matching the build. Every file is checked for CR before handover.
