`6.1 Absorbing & Dispersive` and how to serialize the dispersive data.
We need to address EpsWithDisp, MuWithDisp, RhoWithDisp because they cannot be serialized. We do not change these but add 
some functionality that can produce them AND be serializable. The only consistent way to do that is to represent function 
by so called func values. The dispersion is usually functions, which are a sum of polynomials and inverse polynomials of 
wavelength. And a polynomial / inverse polynomial is easily represented by an array of coefficients (a0+ a1*x + a2*x^2 + …) 
and a power of the whole polynomial, e.g. `(x-a)^(-2)`. The dispersion formulas often take this (x-a) expressions, where this 
a is `lambda_i` – some critical wavelength of that term. So, a term in the expression is that lambda, then array of coefficients, 
and then the power of the overall polynomial and finally a multiplier (e.g.: `-2.5 * (x – 0.0012345)^(-2)`) and the expression 
is simply a sum of the terms, which is the modeled as an arrayof such expressions. This is fully serializable. Then we can create 
the real dispersive functions using the formulas. Finally, if the material is anisotropic, then we model it as a DU: 
Isotropic / Uniaxial / Biaxial / etc. (rho is more complicated) – just make sure that DU cases are globally unique (not already 
used and adjust if necessary). This should go into `C:\GitHub\Berreman\Berreman\Berreman\Dispersion.fs` along with the toEpsWithDisp 
and other members so that to produce the actual dispersive materials used in the system. Perhaps the proposed DispersionModel DU 
could simplify this even further. Perform web research, analyze the code and extend this section to actually cover all these models in detail.
