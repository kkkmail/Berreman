# .manual

This subfolder is for user-authored files: task statements, notes,
attached screenshots, reference documents. The operator authors it;
the spec-writer never auto-injects or overwrites the files here (this
README is written only when the folder does not already contain one).

Agents and workers MAY read this folder -- point them at a file here
when you want it consulted. A cycle writes here only when you
explicitly direct it to (for example, extracting a reference document
into .manual).
